# PAYDAY 3 Trainer — feature reference

A task-oriented PAYDAY 3 trainer workspace: player parameters first, equipment groups next, and mission notes as the final reference area.

| Section | Description |
|---|---|
| Player parameters | Character-related parameters and the settings associated with the selected category. |
| Equipment groups | Equipment categories and the associated selection or configuration options. |
| Mission notes | Session and activity information grouped by the task or context it belongs to. |

The project page follows the same section structure.
